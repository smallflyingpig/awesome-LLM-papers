# LLM 长上下文扩展技术报告

本目录提供同一技术报告的三种交付版本，版式沿用 `tech_blogs` 中既有技术报告的 A4 论文风格、深蓝色标题体系、独立目录页、页眉页脚与参考文献样式。

## PDF

- `output/pdf/LLM长上下文扩展技术报告_中文版.pdf`：中文全文，14 页。
- `output/pdf/LLM_Long_Context_Extension_Technical_Report_EN.pdf`：英文全文，9 页。
- `output/pdf/LLM长上下文扩展技术报告_中英合订版.pdf`：英文在前、中文在后，23 页；两部分各自保留封面、目录和页码。

## LaTeX 源文件

- `llm-long-context-extension-zh.tex`
- `llm-long-context-extension-en.tex`

使用 XeLaTeX 或 Tectonic 编译。文档优先使用 Times New Roman、Arial、Menlo、Songti SC 与 Heiti SC；中文源文件为缺失字体提供了后备配置。
