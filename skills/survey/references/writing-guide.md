# 写作规范

## 语言：中英混合

- **正文**：中文为主，行文流畅自然
- **技术术语**：保留英文原文，**首次出现时括注中文**（如：Attention Mechanism（注意力机制））；再次出现直接用英文
- **模型/方法/数据集名称**：始终用英文（GPT-4、LoRA、HumanEval）
- **表格列名**：中文；表格内容中的专有名词保留英文
- **公式、代码**：全英文
- **章节标题**：`## N. 中文标题（English Subtitle）`

---

## 引用规范（最重要的质量指标）

### 标准引用格式

正文内引用格式（强制）：

```
**论文全名**（第一作者 et al., 会议/期刊, 年份）[arXiv:XXXXXX]
```

示例：
- **Visual Instruction Tuning**（Liu et al., NeurIPS 2023）[arXiv:2304.08485]
- **BLIP-2: Bootstrapping Language-Image Pre-training**（Li et al., ICML 2023）[arXiv:2301.12597]
- **GPT-4 Technical Report**（OpenAI, arXiv 2023）[arXiv:2303.08774]

### 引用字段完整性要求

| 字段 | 说明 | 是否必填 |
|------|------|---------|
| **论文全名**（加粗） | 完整论文标题 | ✅ 必填 |
| 第一作者 et al. | 姓氏，多作者用 et al. | ✅ 必填 |
| 会议/期刊/机构 | NeurIPS / ICML / ICLR / CVPR / ACL / arXiv / OpenAI Tech Report 等 | ✅ 必填 |
| 年份 | 4 位年份 | ✅ 必填 |
| arXiv 编号 | 格式：arXiv:XXXX.XXXXX | ✅ 尽量填，无则省略 |

### 表格中的引用

方法/模型汇总表中，"论文"列格式：

```
论文名（缩写可接受）+ 年份
```

示例：LLaVA-1.5（CVPR 2024）

### 禁止的引用形式

- ❌ `[1][2]` 脚注编号（正文无法直接溯源）
- ❌ 裸论文名，无年份：`LLaVA 提出了...`
- ❌ 无来源的定量声明：`某研究表明准确率提升了 5%`
- ❌ `如 [作者, 年] 所示` 的括号格式（不如内联引用直观）

### 引用密度要求

| 位置 | 引用要求 |
|------|---------|
| 时间线里程碑 | 每个节点：论文名 + 机构 + 会议 + 年份 + arXiv |
| 方法子方向正文 | 每 2-3 句技术性叙述至少有 1 条引用 |
| 方法对比表格 | 每行至少标注论文名（可简写）+ 年份 |
| Benchmark 数字 | 标注该数字来源（技术报告 or 评测论文） |
| 技术结论性声明 | 标注做出该结论的实验来源 |

---

## 学术严谨性

1. **声明有据可查**：每个技术性声明标注来源
2. **数字精确**：参数量、数据集规模、benchmark 分数给原始数字，不用"约"、"大约"
3. **分类自洽**：taxonomy 维度统一，不同类别互斥，无重叠
4. **批判性**：不只罗列方法，分析优缺点和适用场景
5. **时效性**：每篇论文标注发表时间

---

## 格式偏好

- **表格优先**：能用表格展示的信息（对比、汇总）不用长段落
- **Mermaid 图**：taxonomy 分类体系、发展脉络时间线优先用图
- **重要结论加粗**：关键发现、重要数字用 `**加粗**`
- **适度分层**：二级标题（##）和三级标题（###）为主，避免四级

---

## 避免的写法

- 避免：_"该方法取得了显著效果"_（没有数字支撑）
- 改为：_"该方法在 HumanEval 上达到 87.1%，较前代提升 5.3pp"_（**论文名**, 会议, 年份）
- 避免：大段罗列论文摘要的翻译
- 改为：提炼核心贡献 + 与其他方法的关系 + 引用来源
